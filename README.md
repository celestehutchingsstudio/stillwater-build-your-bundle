# Stillwater · Build Your Bundle

Coded prototype for the Stillwater "Build Your Bundle" Shopify case study.

- **Flow 1 · A shopper builds and buys a bundle**: open `index.html` in a browser. The flow goes from the Tide Line Perfume Oil product page into the bundle builder, quick view, the first reward, review, the cart drawer, checkout (including a card error) and confirmation.

- **iPhone version**: open `mobile.html` to see the same prototype inside an iPhone 15 frame.

Use the controls bar to switch between Desktop and iPhone, jump to any designed screen (1–8) or restart. The layout follows `Designs · Flow 1` in the Figma file *Shopify Build Your Bundle · Style guide*.

`assets/` holds the product photos, category banners and gallery images.
